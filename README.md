# UrbanStay-Apartment-Rental-Maintenance-Platform
Designed a normalized MySQL database of 10 tables (owners, buildings, units, tenants, leases, payments, maintenance requests and more) from an ER diagram, using primary and foreign keys and CHECK constraints.
Built a Flask web application with role-based login and modules for leases, payments, maintenance tracking, and reports (occupancy, overdue rent).
Tested 10 scenarios, including invalid logins and constraint violations, and prototyped the interface in Figma. Group project.
